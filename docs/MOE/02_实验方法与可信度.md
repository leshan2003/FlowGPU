## 2. 控制变量

### 20-seed 策略比较

固定：

```text
2 Brain nodes
batch 2
16 copies
C=2
同一模型和 workload
```

变化：随机 workload seed。
比较：每个策略对同一 GPU-only baseline、同一 seed。

### Node × batch

固定：Mixtral 32 层、5 seeds、16 copies、C=2。
变化：nodes=1/2/4，batch=1/2/4。
每个 node 点独立重新 placement。

### C

两套 panel：

- 64 copies / 64 chips：C=1/2/4/8/14；
- 32 copies / 16 chips：C=2/4/8/14；
- D0 C 网格：32-copy budget，C=1/2/4，nodes=1/2/4。

比较 C 时固定 copy budget、芯片集合、workload 和 seed。

### 聚类

固定 GPU plan、hot set、effective copy 数、trace、node、batch、C。
只改变 Brain 专家位置：

```text
unique-balanced vs pair vs full-hyperedge
```

### 模式

- M2/M3 使用相同 Brain hot 位置；
- M3 只额外增加 hot expert 的 GPU 非主副本；
- D0/D1 使用相同 plan、trace、GPU/Brain/node 数。

### DeepInfer 式 EPLB

固定 Mixtral 32 层、5 paired seeds、nodes=1/2/4、batch=1/16、C=2、
32-copy 上限和 Zipf 1.3。所有策略共享同一 GPU primary plan、planning/
evaluation 切分、有效 Brain copy budget 和 evaluation trace。

比较：

```text
coverage
coverage-rebalanced
eplb-0.000
eplb-0.125
eplb-0.250
eplb-0.500
```

指标必须同时包含：

- completion 与 paired speedup；
- Brain assignment fraction；
- node/chip `max(load) / mean(load)`；
- bridge bytes；
- unique experts、冗余 copies 和单专家最大副本数。

## 3. 统计与审计

- 随机 screen：5 paired seeds；
- 关键边界：20 paired seeds；

## 4. 已发现并修复的实验错误

### 4.1 D0 曾被 home-node 污染

早期只改了传播预测，实际 `MoELayerEngine` flow 仍经过 home node。

修复：

- D0 实际 flow 改为 GPU↔expert node；
- D1 保留 home waypoint；
- 新增 D0/D1 event-flow 回归测试。

### 4.2 M2/M3 曾使用不同 placement

早期 M3 独立 coverage plan，和 M2 的 hot/cold 位置不同。

修复：

- M3 继承 M2 的 Brain hot 主副本与 cold GPU 主副本；
- 只增加 hot expert 的 GPU 非主副本。

### 4.3 C 扫描曾经没有形成约束

早期 8-copy budget 在 8-chip 最小拓扑下 C=1 也刚好能放下，C 不可能生效。

修复：

- 使用 32-copy budget；
- 1 node 下 C=1/2/4 分别覆盖 8/16/24 个 hot experts。

### 4.4 原聚类微基准是退化对照

原 C=1 micro 的 unique/pair/full 生成了完全相同布局。

修复：

- 将有区分度的 community stress 单独建模；
- D0 聚类改为逐层选取局部热点，避免选满少数几层的全部专家。

### 4.5 per-GPU 远端路由曾经无效

早期每 expert 只有一份 GPU 副本，却允许 16 个 GPU ingress 访问远端副本。

修复：

- 使用合法 owner-GPU 模型；
- 每个 GPU 保存全部 Mixtral experts；
- 每个 request 绑定 owner GPU；
- 禁止请求访问没有本地副本的远端 GPU。

## 5. 不能混用的比较

- Coverage 完成时间与 Overlay SLO 吞吐不能直接比大小；
- GPU-only 少 16 个 Brain chips，不是 iso-resource；
- 4-layer fast screen 不能外推完整模型；
- D0 的聚类结论不能套到 D1；
- D1 的 home-affinity 结论不能套到 D0；
- synthetic seed CI 不是真实 trace sampling CI；
- 没有价格/功率输入时不能计算 TCO。
